# Hario Switch

Filter brewer, immersion/percolation hybrid. A valve in the base is opened for percolation (drips through like a V60) or closed for full immersion (steeps like a French press, then drains when opened).

---

## Confirmed

### What's actually been used on this unit

- **Every logged brew to date used open (percolation) mode.** Immersion mode has never been used since this journal started.
- Both logged brews (El Perezoso F1, F2) used **tap water** — data from both is invalid. See `corrections.md`.
- Historical (pre-journal) use covered a wider range of techniques on this brewer: full immersion for the whole brew, half immersion/half percolation, straight percolation (V60-style), and intermittent percolation (closed partway through for more extraction). Results were **not comparable** — temperature ranged 80 °C–boiling and water was tap throughout, so none of these constitute a tested recipe. See `context.md`.

### Role in the current investigation

- **Cheaper cross-check for grinder drive-mode equivalence.** Open mode, fixed dose/grind/water/temperature, compare drawdown time — slower drawdown means more fines. Cheaper per data point than espresso and removes puck prep as a confound. See `equipment/arco-grinder.md` for the full protocol.
